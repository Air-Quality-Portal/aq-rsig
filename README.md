# interfaces-template

Template for the custom interfaces

## Pre requisities

- Install node & npm.
  if using nvm, run :
  - `nvm install 20`
  - `nvm use 20`

## Install dependency

run `npm install`

## Run application in Local

- create `.env.local` a copy of `.env.local-sample` with the appropriate tokens
- run `npm run start`

## Bundle using webpack

run `npm run build`
